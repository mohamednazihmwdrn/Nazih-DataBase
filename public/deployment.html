How to Run Locally

Clone the project, install dependencies, and start the unified server: 

# 1. Clone repository
git clone https://github.com/your-username/storepulse-saas.git
cd storepulse-saas

# 2. Install dependencies
npm install

# 3. Start development server (boots SQLite, Express, WebSocket & Dashboards)
npm run dev

# Server will run on:
# -> Web UI: http://localhost:3000
# -> Manager: http://localhost:3000/manager.html
# -> Admin: http://localhost:3000/admin.html

Deploy for FREE on Render.com

  1. Create a free account at Render.com.
  2. Click New + → Web Service → Connect your Git repository.
  3. Configure build settings:
    Runtime: Node
    Build Command: npm run build
    Start Command: npm start
    Plan: Free
  4. Persistent Disk (Optional but recommended): In service settings, attach a Disk mounted at /data so the SQLite database file persists across service deploys!
  5. Click Deploy Web Service. Render provisions SSL and WebSocket routing automatically.

Production Deployment on a $5/mo VPS (Hetzner / DigitalOcean / Linode)

A $5/month cloud VPS (1 vCPU, 1GB RAM) with Ubuntu 22.04 or 24.04 can process millions of invoice payloads seamlessly using this SQLite architecture.

Step A: Setup Node.js & PM2 Process Manager

# SSH into your VPS
ssh root@your-server-ip

# Install Node.js 20.x
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs git sqlite3

# Install PM2 globally
sudo npm install -g pm2

Step B: Deploy & Start StorePulse SaaS

# Clone your app
cd /var/www
git clone https://github.com/your-username/storepulse-saas.git storepulse
cd storepulse

# Install dependencies and build bundle
npm install
npm run build

# Start with PM2
pm2 start dist/server.cjs --name "storepulse-saas"
pm2 startup
pm2 save

Step C: Free Automated HTTPS with Caddy (Recommended) or Nginx

# Install Caddy web server (automatic Let's Encrypt SSL)
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update
sudo apt install caddy

# Edit /etc/caddy/Caddyfile
sudo nano /etc/caddy/Caddyfile

# Paste this configuration:
yourdomain.com {
    reverse_proxy localhost:3000
}

# Reload Caddy
sudo systemctl reload caddy

Step D: Daily SQLite Automated Zero-Downtime Backup

# Add a daily cron job to backup the SQLite file safely:
crontab -e

# Add this line to backup every night at 3:00 AM:
0 3 * * * sqlite3 /var/www/storepulse/data/storepulse.db ".backup '/var/backups/storepulse_$(date +\%F).db'"

Docker & Fly.io Deployment

You can run anywhere using standard Docker containers:

# Build Docker image
docker build -t storepulse-saas .

# Run container with persistent volume for SQLite
docker run -d -p 3000:3000 -v storepulse_data:/app/data --name storepulse storepulse-saas
